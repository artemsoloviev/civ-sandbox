Карта поездок

Приложение с картой для магнитолы. Работает без интернета.

Скачать приложение (1,2 МБ)
Если магнитола скажет, что установка запрещена — разреши «Установку из неизвестных источников» для браузера и нажми ещё раз.
Регионы (карта местности и места) скачиваются уже внутри приложения, на экране «Регионы».
